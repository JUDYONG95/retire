# Retirement Runway

A single-page retirement calculator. Enter your age, savings, contributions, expected returns and retirement spending to see:

- your projected savings at retirement
- the age your money runs out
- the most you can spend each month and still reach your plan age
- the extra monthly saving needed to close any gap

All figures are shown in today's money, with an option to switch to future (nominal) values.

## Run locally

Open `index.html` in a browser. There is no build step and no dependencies apart from Google Fonts (it falls back to system fonts if those are blocked).

## Deploy

Any static host works. For GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.

## Disclaimer

This is a planning estimate, not financial advice. It assumes constant returns and inflation; real results vary.
